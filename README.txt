GROOVEREST QC
================

Simple Laptop / PC Health Checking Tool

Grooverest QC is a simple Windows utility for basic laptop and PC checking
during service and quality-control work.

FEATURES
--------

1. PC Specifications
   - CPU / Processor
   - RAM
   - GPU / Graphics
   - Motherboard
   - Storage
   - Windows / System information

2. Battery Health
   - Design capacity
   - Full-charge capacity
   - Battery health / wear information

3. Disk Health
   - SSD / HDD information
   - Drive status
   - Storage capacity
   - Basic drive health information

HOW TO USE
----------

1. Open GrooverestQC.exe.
2. Wait a few seconds for the system information to load.
3. Select the required checking option.
4. Use the displayed information for basic QC and service checking.

IMPORTANT
---------

- This application is intended for basic checking and QC purposes.
- Battery information depends on what Windows reports.
- Disk health information can vary depending on the drive and Windows support.
- This application does not replace professional hardware diagnostic tools.
- Administrator permission may be required for some hardware information.

REQUIREMENTS
------------

- Windows 10 or Windows 11
- No internet connection is required for basic checking.
